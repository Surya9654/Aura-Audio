DAC Safeguard
When no external DAC is detected, hi-res files (above 48 kHz or 16-bit) are flagged in the Signal Path as being resampled by the system mixer, so you always know what you are really hearing.
Pure Mode (DSP Bypass)
Routes the decoded stream straight to the output, skipping the equalizer and preamp. Your EQ settings are kept and return when you switch it off. Best with an external DAC.
Exclusive Mode (WASAPI, Windows)
Asks Windows for exclusive, low-latency access to the output device so the shared mixer's resampling and volume curve are bypassed. Audio is processed internally as 32-bit float. Best effort: if the device rejects the stream format, Windows falls back to shared mode. Requires a restart.
Use Device Volume
Locks the in-app volume at 100% (no digital attenuation) so loudness is controlled by your device / system / DAC volume. Preserves full bit depth.
Subsonic & DC Rumble Filter 20Hz High-Pass
Steep 4th-order (-24 dB/oct) high-pass filter at 20 Hz. Eliminates 0 Hz DC offset, motherboard electrical ripple, and turntable rumble while leaving musical sub-bass pristine.
Black-Background Noise Gate -65 dBFS
Real-time downward expander that drops output to true digital zero (-∞ dB) during pauses, track gaps, and quiet moments. Cuts out continuous motherboard amp hiss and static.
Lock Screen & System Media Widget Active
Compact lockscreen widget styled after the Full Screen player with glass scrubber and playback controls, designed to sit cleanly alongside other widgets.
